# Suno Prompt Templates — Asset Library

Ready-to-use prompts for every Harmattan Sessions sound. Copy directly into Suno Custom Mode → Style of Music field. Always pair with `[Instrumental]` in Lyrics field.

## How to Use This Library

1. Pick the sound you want
2. Pick a sub-mood variation (5 per sound)
3. Copy the **Style** block into Suno
4. Paste `[Instrumental]` into Lyrics
5. Use the suggested Title or create your own
6. Generate 2 versions per credit
7. If neither works, try a sub-variation, or tweak ONE component

## Pro Tips for Maximum Output Quality

1. **Generate during off-peak hours** — Suno's quality varies with server load. Late nights or early mornings tend to produce better results.

2. **Don't burn 10 credits on the same prompt** — If 3 attempts don't hit, the prompt structure is wrong. Re-architect.

3. **Save your BEST winning prompts** — Build a personal `winners.md` file. These are gold.

4. **Track which references work** — Some Suno seeds respond better to "Sarz" than "Tay Iwar" for the same intended vibe. Document.

5. **Test on real speakers before extending** — Don't waste credits extending a track that sounds bad in headphones.

6. **Save in highest quality** — Always download WAV, never MP3. Mixing requires lossless source.

## Adding New Templates

When you discover a winning prompt:

1. Test it 5 times with different seeds — does it produce consistent quality?
2. If yes, add it to this file under the appropriate sound
3. Note the date and any specific Suno version it was tested on
4. Keep the cultural lineage notes (which reference artist inspired it)

The library grows with the catalog. Year 2 should have 40+ templates.

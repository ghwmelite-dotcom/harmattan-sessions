# Singles Plan — Monthly Release Engine

Supersedes the two-EP framing in `distrokid-release-plan.md`. Strategy: **one single per month**, each landing on streaming + a YouTube Short, sequenced for editorial pickup and steady algorithm presence.

---

## The cadence

One single per month. Each single = the same repeatable loop:

```
Day −14   Upload WAV to DistroKid, schedule release, pitch via Spotify for Artists
Day  0    Single goes live (Spotify/Apple/Tidal/Amazon) + YouTube Short same day
Day 0–7   feature.fm link everywhere; free playlist submissions; newsletter
Day 7     Track folded into the next YouTube long-form mix
Day 30    Next single repeats the loop
```

One streaming release + one Short per month, plus the track feeds a mix. No stuffing, one editorial pitch per release.

- [ ] **YouTube Short** (see below) — same day as streaming

- [ ] **Free playlist** submissions (DailyPlaylists + a few SubmitHub credits)
- [ ] Fold the track into that month's long-form YouTube mix (Day 7)

## The YouTube Short (per single)

The daily/weekly content engine — vertical, 15–30s, one per single minimum.

- **Format:** 1080×1920, the single's strongest 15–30s hook
- **Visual:** the Akua single cover with subtle motion (boomerang loop, same technique as the launch video), OR a vertical crop of the scene
- **Text:** track name + "Harmattan Sessions" + "full track on Spotify ↗"
- **Audio:** start ON the hook — no intro fade (Shorts retention is brutal in the first 2s)
- **Caption:** 1 line + 3 hashtags (#afrolofi #ghana #lofi)
- **Cadence:** 1 Short per single minimum; ideally repurpose 2–3 hooks per track for more at-bats
- Cross-post the same vertical to TikTok + Instagram Reels

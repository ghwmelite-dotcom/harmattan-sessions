## Cross-platform rules (all 3)

- **Upload the video file natively** to each — don't post a YouTube link as the main content
- **Hook in the first 2 seconds visually + first line of text** — retention is everything
- **Engage in the first hour** — reply to every comment fast; early engagement = reach
- **Best post times (GMT, Accra):** evenings 18:00–21:00 (diaspora + EU/US overlap), or 12:00–13:00
- **Post the same Short to all platforms within the same day** for a coordinated launch pulse
- **One CTA per post** — don't ask for follow + like + save + link-click; pick the one that matters (watch → link)

## Self-critique
The biggest risk: posting a polished promo that reads as an *ad*, which kills organic reach. Mitigation — the "I made a beat from a taxi rank" / "lofi girl from Accra" angles lead with a *story or curiosity*, not "check out my new release." Story travels; ads don't.
